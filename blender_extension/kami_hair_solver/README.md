# 髪

Blender 5.2 Hair Curves 用の非線形 Cosserat ロッド有限要素接触ソルバーです。

3D Viewのサイドバー「髪」で入力する髪と衝突メッシュを指定し、「髪を計算」を実行します。「髪を準備」は入力検査だけを先に行いたい場合に使えます。開始から終了までのアニメーションをGPUへ常駐させ、転送・フレーム・サブステップ・反復・残り時間をパネルに表示します。Escで中止できます。元オブジェクトは変更せず、結果を別 Hair Curves と専用 `.khc` キャッシュへ保存します。

PBD、XPBD、位置拘束投影、CPUソルバーへのフォールバックは使用しません。髪同士の自己衝突は行いません。

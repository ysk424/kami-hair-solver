# 髪3・soft実験

Blender 5.2 Hair Curves 用の非線形 Cosserat ロッド有限要素接触ソルバーです。

3D Viewのサイドバー「髪3」で入力する髪と衝突メッシュを指定し、「髪を計算」を実行します。「髪を準備」は入力検査だけを先に行いたい場合に使えます。開始から終了までのアニメーションをGPUへ常駐させ、転送・フレーム・可変時間ステップ・反復・残り時間をパネルに表示します。Escで中止できます。元オブジェクトは変更せず、結果を別 Hair Curves と専用 `.khc` キャッシュへ保存します。安定版「髪」と同時に有効化できます。

「softコライダー（実験）」は、相対運動が安全でhard求解が収束する時間区間では従来の剛体経路を使います。相対sweepが制限されるかhard求解が失敗した区間だけ、BODY頂点をアンカー付きの連成未知数へ切り替え、直前の実行可能な髪位置から再試行します。変形結果は元BODYとは別の「softコライダー_計算結果」と `.soft-collider` サイドカーへ保存します。このBODYは慣性や面内・曲げ弾性を持たない準静的な退避モデルです。

hardのNewton上限到達もsoft再試行の対象です。髪の予測移動が大きすぎる区間やBVH候補が過大な相対sweepは、巨大な単一CUDA探索へ入る前に時間幅を縮小します。進捗には成功区間、総試行、sweep縮小、soft試行と、sweep事前制限・相対運動sweep・line-search CCDを区別して表示します。

PBD、XPBD、位置拘束投影、CPUソルバーへのフォールバックは使用しません。髪同士の自己衝突は行いません。

「最小動力学長」は0で無効です。正の値では短い髪を毛先接線方向へ同じCosserat材料で非表示延長し、表示とキャッシュには元の長さだけを反映します。仮想部分は質量・弾性・重力には参加しますが、BODY接触には参加しません。

設計検討では、ZOZO, Inc.の公開プロジェクト [ppf-contact-solver](https://github.com/st-tech/ppf-contact-solver) の接触バリア剛性とTOI制限付き時間進行を参考にしました。本ソルバーは同プロジェクトのソースコードを取り込まず独立に実装しており、この謝辞はZOZO, Inc.による承認、提携または本ソルバーへの権利帰属を示すものではありません。
